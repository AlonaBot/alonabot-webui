# AlonaBot WebUI

[简体中文](README.zh-CN.md)

Manage plugins, platform accounts, models, profiles, conversations, logs, and permissions from the Core web interface.

## Quick start

Use Core v0.3.0 or later. On the machine running Core:

```fish
alonabot install --source AlonaBot/alonabot-webui --yes
```

Open the Core web address and sign in with its management token.
