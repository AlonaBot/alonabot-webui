# alonabot-webui 0.1.1

## 新增

- 商店可以检查组件的最新发行，再通过预填的 GitHub Issue 提交收录。调用方也可以用 `GET /store/check` 查询已发布组件的身份。
- 商店显示各角色的组件数量，支持按标签搜索、按名称或 Star 数排序，每页显示九张卡片。搜索和筛选复用当前快照；页面显示抓取时间，刷新失败时会报错并保留上次结果。
- 本机首次登录可领取待确认的管理令牌。刷新页面会恢复已有管理会话。

## 修复

- 添加的 Adapter 与已安装项冲突时，商店根据 Core 的结果提供「替换」入口。已安装的卡片仍可打开详情和更新。
- 发行资产损坏或保存的插件源无效时，商店显示实际错误。发布检查会拒绝 manifest 来源与 `release.json` 不一致的安装包。
