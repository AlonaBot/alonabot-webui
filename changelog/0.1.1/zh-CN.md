# alonabot-webui 0.1.1

## 新增

- 插件商店发布表单：填写仓库、检查最新 Release，再经预填的 GitHub Issue 向所选插件源提交条目。
- `GET /store/check` 后台路由，返回已发布组件解析出的展示身份，不落任何存储。
- 商店角色筛选带各角色数量、星数与名称排序，以及每页九张卡片的分页布局。
- 商店刷新入口。进入商店、切换源与手动刷新会抓取新快照；搜索、角色、排序与分页复用已存快照，不再访问 GitHub。

## 变更

- 商店搜索在名称、描述、仓库与作者之外，也覆盖标签。
- 已安装卡片同时保留更新动作与详情入口，来自其他源的已装组件仍然可达。
- 商店持续显示快照抓取时间；已有快照时刷新失败，保留完整刷新错误。
- 本机首次登录领取待确认管理令牌供操作者保存，页面重载后恢复已有管理会话。

## 修复

- 同类替换沿用 Core 的确认结果；Adapter 冲突返回 `ALREADY_EXISTS` 时给出 `Replace` 路径，而不是只显示错误。
- 发布检查不再把损坏的 Release 资产报告为「没有 Release」；只有缺少 `releases/latest` 端点才视为未发布。
- 包内 manifest 的 source 与 `release.json` 不一致时，商店检查现在拒绝，与 Core 安装预检一致。
- 浏览器里损坏的插件源记录会显示实际错误，不再静默回落到默认源。
- 刷新进行中锁定商店筛选、分页与源操作，已完成的刷新结果不再被丢弃。
