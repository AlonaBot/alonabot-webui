# alonabot-webui 0.3.1 - 2026-11-23

### Fixed

- The sign-in token, global search, plugin search and conversation search fields no longer show an extra inner focus box; the conversation search field matches the other search heights. See [PR #16](https://github.com/AlonaBot/alonabot-webui/pull/16).
- Checked checkboxes keep their checked style on hover instead of appearing unchecked. See [PR #16](https://github.com/AlonaBot/alonabot-webui/pull/16).

### Distribution and upgrade

- Works with Core v0.3.0 and updates directly from 0.3.0; configuration and data are retained.
