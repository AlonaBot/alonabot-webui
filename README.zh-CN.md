# AlonaBot 官方 WebUI

[English](README.md)

通过 Core 网页管理插件、平台账号、模型、配置文件、会话、日志与权限。

## 快速使用

使用 Core v0.3.0 或更高版本，在运行 Core 的机器上执行：

```fish
alonabot install --source AlonaBot/alonabot-webui --yes
```

打开 Core 网页地址，使用管理 token 登录。
